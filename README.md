# Student-Registration-System & Contact Intelligence System

**About the Project**

The Student Registration & Contact Intelligence System is a Python-based application designed to manage student information efficiently. It allows users to register, search, update and analyze student records through a simple menu-driven interface.

**Features**

- Displays all student records.
- Search students using different search options.
- Register new students.
- Prevent duplicate student registrations.
- Update existing student details.
- Prevent duplicate entries during updates.
- Delete existing student records.
- Generate analytics reports.
- Exit the application safely.

**Project Files**

- main.py - Main application.
- analytics.py - Generates student analytics reports.
- loader.py - Loads student data.
- validator.py - Validates student information.
- students_clean.csv - Student sample dataset.
- contacts.csv - Sample contact dataset.

**How to Run**

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command

   python main.py
